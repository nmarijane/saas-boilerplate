## Quick Start

Clone the repository and get your SaaS running in under 2 minutes:

```bash
git clone https://github.com/your-org/saas-boilerplate.git my-saas
cd my-saas
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and you're live.

## What's Included

This boilerplate comes with everything you need to launch a production-ready SaaS:

- **Authentication** — Email, Google, GitHub login with MFA support
- **Billing** — Stripe subscriptions with checkout, portal, and webhooks
- **Multi-tenancy** — Organizations with role-based access control
- **AI Chat** — Multi-provider AI with credit metering system
- **Admin Panel** — User management, audit log, feature flags
- **API Keys** — SHA-256 hashed, scoped API key management

## Customization

Every feature is a standalone module in `src/features/`. Remove what you don't need, keep what you do.

Need help? Check the [Setup Guide](/docs/setup) or open an issue on GitHub.
