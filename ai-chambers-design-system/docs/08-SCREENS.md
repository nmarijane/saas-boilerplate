# Screen inventory and anticipated settings

| Screen                  | Shared composition                                         | Required special states                                   |
| ----------------------- | ---------------------------------------------------------- | --------------------------------------------------------- |
| Overview                | Compact action queue, recent runs and assigned solutions   | Empty onboarding, no invented efficiency metrics          |
| AI Tools                | RecordTable, optional grid, tool inspector                 | Form/Chat, price/access, bookmarks                        |
| Tailored Solutions      | Same table: type, trigger, health, last activity           | Assigned workspace only, paused, connection needed        |
| Tool administration     | Details/Interface/Execution/Access & pricing/Publish tabs  | Draft, invalid schema, test pending, conflict             |
| Solution administration | Client, type, trigger, workflow, connections, action scope | Not connected, approval policy, test/publish guards       |
| Disclosure form         | Supplied schema, summary, hosted payment, exact terms      | Upload/discount/payment failures and uncertain completion |
| Chat                    | History, scoped conversation, source inspector             | Streaming, partial, stopped, source unavailable           |
| Runs & Results          | Table + Details/Files/Activity                             | Processing, review, completed, failed, cancel pending     |
| Documents               | Table + private preview                                    | Permission lost, expired link, unavailable                |
| Workspace General       | Identity and regional/member defaults                      | Dirty, saving, conflict                                   |
| Members & roles         | Table + permission inspector                               | Invitation expiry, owner protected, role changed          |
| Tool access             | Assignments and backend entitlements                       | Revoked, plan limit, pending changes                      |
| Connections             | Table + dependency/permission/activity inspector           | Expired, reconnect, disconnect confirmation               |
| Billing                 | Authorised plan, usage, invoices and portal                | Payment failed, unknown invoice, denied                   |
| Preferences             | Appearance, tables/navigation, forms, accessibility        | Reset preview, local versus server save                   |
| Notifications           | Event/channel matrix, digest, quiet hours                  | Essential notices locked, delivery error                  |
| Security                | Backend-supported MFA, sessions and passkeys               | Step-up auth, revoke confirmation                         |
| Platform clients        | Table + client inspector                                   | Explicit tenant context, restricted operations            |
| Audit log               | Read-only table + event inspector                          | Redacted payload, authorised filters                      |

Only records, local settings/preferences and validation-only disclosure examples are executable here. This inventory does not mean all routes are implemented.

## Personal preferences

Theme Light/Dark/System; approved text scaling; Compact/Comfortable density; Table/Grid; page size10/25/50; restore view; remember columns/widths/sort/filter; expanded/collapsed navigation; remembered submenus; panel/full-page details; prefill profile; restore safe drafts; unsaved guard; reduced motion Follow system/On; shortcut hints. Focus indicators cannot be turned off. Text scaling must preserve reflow.

## Notifications

Events: completed/failed run, review ready, approval assigned, solution paused, connection attention, workspace invitation, product updates. In-app/email independently where allowed; immediate/daily routine digest with time/timezone; combine same-run updates; quiet hours. Critical security/action-required delivery is backend policy, not a cosmetic preference.

## Workspace defaults

Logo, name, identifier, contact email, timezone, date/time format, language and billing-controlled currency. New-member role, assigned tool access and approval defaults are policy-backed. Matter reference prefix applies only if the product actually generates references. Never invent subscription allowances from demonstration screenshots.
