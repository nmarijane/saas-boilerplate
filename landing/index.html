Your agents don't waste tokens figuring out the codebase — they have everything from day one.

✓ Architecture (18 feature modules)

Start in 30 seconds

No database setup. No env vars. PGlite runs in-memory.

# Clone and start
$ git clone https://github.com/nmarijane/saas-boilerplate.git my-saas
$ cd my-saas && npm install
$ npm run dev
# Seed dev accounts (admin@example.com / admin123)
$ npm run db:seed
→ Open http://localhost:3000
