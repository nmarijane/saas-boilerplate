Atomic Feature Sets

Each feature is isolated. Remove what you don't need — delete the folder, done.

Core

Authentication (email, Google, GitHub, MFA), multi-tenancy (orgs, RBAC), Stripe billing (checkout, portal, webhooks), onboarding wizard.

Platform

Dashboard with stats, admin panel (users, orgs, audit log, feature flags, changelog, metrics), settings, in-app notifications.

Developer

API keys (SHA-256), webhooks (HMAC-SHA256), feature flags, event bus (17 types), audit log, file upload (S3), rate limiting, email templates.

Build & Ship

Focus 100% on business logic. Auth, billing, admin — already done.

terminal 
$ git clone https://github.com/nmarijane/saas-boilerplate.git my-saas
$ cd my-saas && npm install
$ npm run dev

# Seed dev accounts (admin@example.com / admin123)
$ npm run db:seed

→ Open http://localhost:3000
